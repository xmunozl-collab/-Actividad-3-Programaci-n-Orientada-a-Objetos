## Descripción

Este repositorio contiene la solución en Python (con la librería tkinter) de los ejercicios 8.2 y 8.3
del libro *Ejercicios de programación orientada a objetos con Java y UML* de Leonardo Bermón Angarita,
solicitados en la Actividad 3. Incluye la parte propuesta de cada ejercicio.

## Cómo ejecutar

Se necesita Python 3 con tkinter (viene incluido en el instalador oficial de Python para Windows y macOS).
Cada ejercicio se ejecuta desde su archivo principal:

\`\`\`bash
python3 principal_notas.py
python3 principal_figuras.py
\`\`\`

Las imágenes de las figuras (archivos `.png`) deben estar en la misma carpeta que los archivos `.py`.
